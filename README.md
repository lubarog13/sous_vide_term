# sous_vide_term

Мобильное приложение **«Умный градусник»** для управления термостатом на базе Arduino по **Bluetooth Classic (SPP)**. Устройство поддерживает заданную температуру воды (су-вид, йогурт, творог и т.п.) и при необходимости периодически перемешивает содержимое.

## Возможности

### Главный экран
- Подключение к устройству: сканирование, выбор из списка, сохранение последнего подключения.
- **Текущая и целевая температура** — отображение и задание с шагом 0,1°.
- **Таймер** — длительность, обратный отсчёт, круговой индикатор прогресса, старт/пауза/сброс.
- **Программы** — быстрый выбор из сохранённых сценариев (picker).
- **Погрешность температуры** — допустимое отклонение (±).
- **Перемешивание** — вкл/выкл.
- **Синхронизация** — при расхождении состояния с устройством предлагается выровнять параметры.
- Сохранение и обновление пользовательской программы с главного экрана.

### Вкладка «Программы»
- Список всех программ из локальной БД (в т.ч. предустановленные рецепты).
- Выбор программы одним нажатием — параметры переносятся на главный экран.
- Список обновляется при каждом показе вкладки.

### Настройки
- Тёмная / светлая тема.
- Единицы температуры: °C / °F.
- Имя Bluetooth-устройства для поиска при сканировании (переопределяет значение из `.env`).
- Руководство пользователя и пользовательское соглашение.

При возврате на главный экран из настроек подтягиваются актуальные единицы температуры и имя устройства.


## Протокол обмена с устройством

Текстовые команды по строкам (`\n`):

| Направление | Формат | Описание |
|-------------|--------|----------|
| → устройство | `Tt:<temp>` | целевая температура |
| → | `O:<offset>` | погрешность |
| → | `S:0` / `S:1` | перемешивание выкл/вкл |
| → | `M:<minutes>` | длительность в минутах |
| → | `START` / `STOP` | запуск / остановка |
| ← устройство | `Ct:<temp>` | текущая температура |
| ← | `Tr:0` / `Tr:1` | таймер остановлен / идёт |
| ← | `Tt:`, `O:`, `M:`, `S:` | эхо/состояние параметров |

## Требования

- Flutter SDK, совместимый с `sdk: ^3.11.5` в `pubspec.yaml`.
- **Android** — основная целевая платформа (Bluetooth Classic, разрешения на Bluetooth и геолокацию при сканировании).
- Физическое устройство или эмулятор с поддержкой нужных разрешений для отладки Bluetooth.

## Настройка перед запуском

1. Клонируйте репозиторий и перейдите в каталог проекта.

2. Создайте файл `.env` в корне (если его нет):

```env
DEVICE_NAME="SmartThermostat"
```

Имя должно совпадать с именем Bluetooth-устройства Arduino (или задайте своё в настройках приложения).

## Запуск

```bash
flutter pub get
flutter run
```
